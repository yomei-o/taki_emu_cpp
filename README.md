# taki_emu_cpp

滝のシミュレータ。**水を粒子として解いて、粒子が動いた軌跡をそのまま線として焼き付けます。**
滝の絵を描いているのではなく、水が岩を落ちた結果として線が引かれる。
計算も描画もすべて C++（テキストのみ [olive.c](https://github.com/tsoding/olive.c)、あとは自前の HDR 加算バッファ）で、
Emscripten で WASM にして走らせます。作りは [hanabi_emu_cpp](https://github.com/yomei-o/hanabi_emu_cpp) と同じ ABI・同じハーネス。

## ▶ WASM デモ

### **https://yomei-o.github.io/taki_emu_cpp/wasmdist/taki_os/**

**岩の形**を切り替えると、一枚の滝・段瀑・三筋・樋・岩場になります。
クリックでその場所の水が跳ねます。**⛶ フルスクリーン**（または F キー）で線だけの全画面に。

## 何をシミュレーションしているか

入力は**重力と地形と流量だけ**です。滝の形も筋の本数も、描いたものではなく計算の結果です。

### 1. 岩 — 高さ場 H(x, z)

落ち口（リップ）の直下 3.4 m ぶんを一気に落として「壁」にしています。
高さ場なので真の垂直は作れませんが、勾配が 5 前後（79°）あれば水は面を離れて自由落下します。

```
z >= LIP        : H = TOP + (z-LIP)*0.055        上流のゆるい川床
ZF <= z < LIP   : H = TOP - (TOP-LEDGE)*u^0.55   壁（u=0 が落ち口）
BASE <= z < ZF  : H = LEDGE - ... smoothstep      壁の下の瀬
z < BASE        : 滝壺（椀）＋ 手前の土手
```

そこへ**溝（ガリー）**を彫ります。

```
H -= depth * exp(-((x-gx)/w)^2) * (z の窓)
```

**筋は描いていません。**水が自分で溝に集まって筋になります。
「分岐」プリセットは溝を 3 本彫っただけで、三筋の滝が出てきます。

### 2. 落下 — 着水速度は積分の結果

粒子は重力で自由落下します。落差 h に対して着水速度は v = √(2gh) になるはずで、
これを**確かめられるようにしてあります**。粒子ごとに「今回いちばん高かった所」を覚えていて、
ぶつかった瞬間に (落差 h, 速さ |v|) を対で記録します。画面下に

```
実測 落差 14.2 m → 着水 16.5 m/s   （√(2gh) = 16.7 m/s）
```

のように並べて出しているので、目で照合できます。**表から読んだ値ではありません。**

### 3. 水らしさ — 格子の圧力と粘性

粒子を落とすだけだと砂になります。水にするために、粒子を格子に撒いて

```
ρ = セルの粒子数
p = K · max(0, ρ − ρ₀)          ← 混みすぎたら押し返す
v ← v − ∇p·dt                    圧力
v ← v + (⟨v⟩_cell − v)·visc      粘性（近傍と速度を揃える）
```

これで水は面に広がり、束になって落ち、滝壺で跳ねます。**すべて O(N)** なので 10 万粒でも回ります。

> **ρ₀ は粒子数から決めないといけません。** 固定値にすると、粒子を増やしただけで圧力が爆発します
> （実際それで水が横に吹き飛んで蝶の羽になりました）。`ρ₀ = N/780`、`K = 110/ρ₀` として
> **K·ρ₀ ＝ 水の固さ**を一定に保っています。

### 4. 岩との衝突と白泡

高さ場の勾配から法線を作り、法線成分をはね返して接線成分に摩擦をかけます。
強く当たった粒子には**泡（foam）**を立てて白く明るくします。**白泡は速度の記録**です。

### 5. 線 — ここが本題

毎フレーム、粒子の「前の位置 → 今の位置」を HDR 加算バッファに引きます。
バッファは毎フレーム少しずつ減衰するので、線は軌跡として尾を引きます。

**単位長さあたり一定量**を置いているのがミソで、こうすると速く動く粒子ほど長く明るい線になり、
止まった水は暗くなります。線の明るさがそのまま流速の地図になっています。

岩も面では塗らず、等高線と縦の稜線という**線**で描いています（水と同じ言葉で描きたいので）。

## つまみ

水の量 / 流量 / 水の広がり / 重力 / 粘り / 岩の摩擦 / しぶき / 線の残り（尾の長さ）/ 線の明るさ /
視点の向き・高さ・距離 / 岩の形 / 色（白青・藍・玉虫）/ 視点の自動回転。

重力を月の 1.62 にすると、同じ落差でも着水速度が √ に従って落ちるのが数字で見えます。

## ビルド

```bash
./build.sh taki_os          # → wasmdist/taki_os/{sim.js,sim.wasm}
```

ネイティブ自己テスト（PNG を書き出す。ブラウザなしで絵を確かめられる）:

```bash
clang++ -O2 -std=c++17 -I. -o taki_test src/taki_os.cpp
./taki_test 600 2 preview.png          # フレーム数 / 岩の形 / 出力
CAM="0 80 55 900" ./taki_test 500 2 top.png    # 真上から（診断用）
```
